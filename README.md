# coursework # Реестр СЗИ от НСД

Курсовая работа по теме: «Разработка программного обеспечения для ведения реестра СЗИ от НСД»

## Требования
- Go 1.22+
- Fyne UI Framework
- PostgreSQL
- Docker + Docker Compose

## Запуск

1. Убедитесь, что Docker и Go установлены
2. Запустите базу данных:
   ```bash
   docker-compose up -d
   ```
3. Запустите приложение:
   ```bash
   go run main.go
   ```

## Функциональные возможности

- Аутентификация пользователей
- Управление записями СЗИ (добавление, редактирование, удаление)
- Поиск и фильтрация записей по различным критериям:
  - Наименование СЗИ
  - Тип СЗИ (СКЗИ, ОС, СЗИ КС и т.д.)
  - Статус (актуально, просрочено, снято)
  - Место установки
  - Производитель
  - Версия программного обеспечения
  - Контактное лицо
- Автоматическое определение статуса (актуально/просрочено) на основе даты истечения сертификата
- Дополнительная информация о СЗИ:
  - Производитель
  - Версия программного обеспечения
  - Контактное лицо для поддержки
  - Ссылка на документацию/сертификаты
- Индексы для улучшения производительности поиска
- История изменений записей
