# Coursework v2

Новая версия рабочего интерфейса реестра СЗИ.

## Что изменилось

- темная графитовая тема с зеленым акцентом по мотивам `course_work-main/music-manager`;
- живой поиск по названию, сертификату, производителю, месту установки и типу;
- фильтрация по статусу и типу СЗИ;
- фильтрация по классу защищённости СВТ, уровню доверия, классу АС и схеме сертификации;
- сортировка по названию, сроку действия и статусу;
- два режима просмотра: карточки и компактный список;
- единое обновление данных после удаления и ручное обновление после добавления или редактирования;
- используются существующие модели, сервисы и формы CRUD текущего проекта.
- при первом запуске пустого реестра добавляются демонстрационные записи по известным продуктам СЗИ/ОС; данные встроены в Go-код и сохраняются непосредственно в PostgreSQL, внешний файл наполнения не используется.

Карточка v2 содержит поля реестра ФСТЭК: функциональную категорию СЗИ, класс защищённости СВТ от 1 до 6, уровень доверия от 1 до 6, класс АС, заявителя или разработчика, версию, номер и схему сертификации, даты сертификата. Для внутреннего учёта добавлены место установки и ответственный сотрудник. Технические идентификаторы используются только внутри БД и не показываются пользователю.

## Запуск

Из папки `coursework-v2`:

```bash
cp .env.example .env
# Заполните секреты в .env, затем:
set -a; . ./.env; set +a
docker compose --env-file .env up -d
go run .
```

Перед запуском должны быть доступны переменные подключения к PostgreSQL, которые использует основной проект.

Если запускаете команды из корня репозитория:

```bash
docker compose --env-file coursework-v2/.env -f coursework-v2/docker-compose.yml up -d
set -a; . coursework-v2/.env; set +a
go run ./coursework-v2
```

Для новой версии используется `localhost:5434`, пользователь приложения `szi_app`, база `szi_registry`. Пароли задаются только в локальном `.env` и не попадают в Git.

При первом создании тома `coursework_v2_pg_data` скрипт `db/init/01-create-app-role.sh` создаёт роль `szi_app` и выдаёт ей доступ к базе. Для уже существующего тома init-скрипты PostgreSQL повторно не запускаются. В этом случае после заполнения `.env` выполните `./db/ensure-app-role.sh`, затем `DB_PASSWORD=... DB_PORT=5434 go run .`.

Экспорт выполняется кнопкой «Экспорт CSV» через системный диалог выбора файла. Программа не строит путь из текстового ввода пользователя.
